# Getting hired

This phase turns the skills from the rest of the course on the job search itself. You read 300 job postings as data to decide what to learn next, practise the six SQL questions that come up again and again in analyst interviews, build one small portfolio project from question to one page write-up, and score your resume against real postings to see what is missing. Every lesson runs on Python 3.9 or later with the standard library only, and every dataset is synthetic.

1. [Read job postings like data](01-read-job-postings-like-data/)
2. [SQL interview questions](02-sql-interview-questions/)
3. [Portfolio project end to end](03-portfolio-project-end-to-end/)
4. [Match your resume to a posting](04-match-your-resume-to-a-posting/)
